# 💎 Mejores Prácticas - FinanzasScanner

## 📝 Guía para un Control Financiero Efectivo

### 🎯 Configuración Inicial Óptima

#### 1. Define tu Presupuesto Correctamente

**Regla 50/30/20** (Recomendada):
- **50%** - Gastos esenciales (Casa, Comida, Transporte, Salud)
- **30%** - Gastos personales (Familia, Viajes, Otros)
- **20%** - Ahorro (mantén tu presupuesto al 80% del ingreso)

**En la app:**
```
Ingreso: $15,000
Presupuesto recomendado: $12,000 (80%)
```

#### 2. Categorización Inteligente

| Categoría | Incluye | % Recomendado |
|-----------|---------|---------------|
| 🏠 Casa | Alquiler, servicios, internet, mantenimiento | 30% |
| 🍔 Comida | Supermercado, restaurantes, delivery | 15% |
| 👨‍👩‍👧 Familia | Educación, ropa, entretenimiento | 10% |
| 🚗 Transporte | Combustible, transporte público, mantenimiento | 10% |
| ❤️ Salud | Medicamentos, médicos, prepaga | 10% |
| 📄 Monotributo | Impuestos, servicios profesionales | 5% |
| ✈️ Viajes | Ocasional, vacaciones planificadas | 5% |
| 📦 Otros | Imprevistos, varios | 5% |

## 📸 Escaneo Efectivo de Tickets

### ✅ Cómo Tomar la Foto Perfecta

**Iluminación:**
- ✅ Luz natural o buena iluminación artificial
- ✅ Evita sombras sobre el ticket
- ❌ No uses flash directo (puede reflejar)

**Enfoque:**
- ✅ Ticket completo en el encuadre
- ✅ Letras nítidas y legibles
- ✅ Ticket plano (no arrugado)
- ❌ No tomes fotos en ángulo

**Timing:**
- ✅ Escanea el mismo día de la compra
- ✅ Revisa los datos antes de guardar
- ❌ No acumules tickets para escanear después

### 🎯 Mejora la Precisión del OCR

1. **Fondos claros**: Coloca el ticket sobre una superficie blanca
2. **Sin pliegues**: Estira bien el ticket
3. **Texto grande**: El OCR lee mejor tickets con texto grande
4. **Contraste**: Tinta oscura sobre fondo blanco funciona mejor

**Si el OCR falla:**
- No te preocupes, siempre puedes editar manualmente
- Los datos pre-llenados son solo ayuda, no son obligatorios
- Aprende de los errores: si un comercio siempre falla, edita manualmente

## 💳 Gestión de Métodos de Pago

### Estrategia de Uso

**Efectivo:**
- ✅ Gastos pequeños diarios
- ✅ Comercios sin POS
- ✅ Control directo del gasto

**Transferencia:**
- ✅ Pagos grandes (alquiler, servicios)
- ✅ Pagos programados
- ✅ Sin comisiones

**Tarjeta:**
- ✅ Compras medianas/grandes
- ✅ Aprovechar beneficios y descuentos
- ✅ Seguridad y respaldo

### Nomenclatura de Tarjetas

**❌ Mal:**
- "Tarjeta 1"
- "La roja"
- "Mi tarjeta"

**✅ Bien:**
- "Visa Gold BBVA"
- "MasterCard Platino"
- "Amex Blue"

**Ventajas:**
- Identifica rápidamente cuál usaste
- Compara consumo entre tarjetas
- Optimiza el uso según beneficios

## 📊 Interpretación de Estadísticas

### Termómetro del Mes

| Porcentaje | Estado | Acción |
|-----------|--------|--------|
| 0-50% | 🟢 Excelente | Continúa así |
| 51-75% | 🟡 Normal | Atento al gasto |
| 76-99% | 🟠 Precaución | Reduce gastos |
| 100%+ | 🔴 Alerta | Acción inmediata |

**Cuando estás en rojo:**
1. Revisa categoría con más gasto
2. Identifica gastos innecesarios
3. Aplica recortes inmediatos
4. Considera aumentar presupuesto si es persistente

### Análisis de Categorías

**Pregunta clave:** ¿Qué categoría consume más de lo esperado?

**Ejemplo:**
```
Comida: 35% (esperado: 15%)
↓
Acción: Reducir delivery, cocinar más en casa
```

**Herramienta:**
```
Exporta CSV → Analiza en hoja de cálculo → Crea plan de reducción
```

### Uso de Tarjetas

**Distribución ideal:**
- No concentres todo en una tarjeta
- Aprovecha beneficios específicos de cada una
- Controla límites de crédito

**Señales de alerta:**
- Una tarjeta con >70% del gasto total
- Consumo creciente mes a mes sin justificación
- Uso de tarjeta para gastos que podrías pagar en efectivo

## 💡 Tips Avanzados

### 1. Categorías Flexibles

**Gastos compartidos en pareja/familia:**
```
Categoría: Familia
Comercio: "Super (50% mío)"
Nota mental: Registra solo tu parte
```

### 2. Gastos Recurrentes

**Identificación rápida:**
```
Comercio: "Alquiler - Enero"
Comercio: "Alquiler - Febrero"
etc.
```

**Ventaja:** Filtro por "Alquiler" muestra historial completo

### 3. Control de Impulsos

**Antes de comprar algo grande:**
1. Abre el Dashboard
2. Mira el termómetro
3. Pregunta: "¿Tengo margen?"
4. Si estás >80%, pospone la compra

### 4. Meta de Ahorro

**Estrategia:**
```
Ingreso: $15,000
Presupuesto: $11,250 (75%)
Ahorro garantizado: $3,750 (25%)
```

**Gamificación:**
- Si terminas el mes <70% = ¡Premio extra de ahorro!
- Si superas 100% = Análisis profundo del mes

### 5. Gestión de Imprevistos

**Crea un buffer:**
```
Ingreso: $15,000
Presupuesto base: $10,500 (70%)
Buffer imprevistos: $1,500 (10%)
Ahorro: $3,000 (20%)
```

## 🚫 Errores Comunes a Evitar

### 1. No Registrar Gastos Pequeños
**Error:** "Solo $50, no importa"
**Realidad:** 10 gastos de $50 = $500 = 3.3% del presupuesto

### 2. Categorización Inconsistente
**Error:** 
- Compra 1: "Comida" → Super Dia
- Compra 2: "Familia" → Super Dia
**Solución:** Decide un criterio y mantenlo

### 3. Ignorar el Termómetro
**Error:** Llegar al 95% el día 15 del mes
**Solución:** Revisa semanalmente y actúa temprano

### 4. No Revisar Distribución de Categorías
**Error:** Gastar 40% en Viajes sin darte cuenta
**Solución:** Análisis mensual de categorías

### 5. Presupuesto Irrealista
**Error:** Presupuesto de $5,000 con ingreso de $15,000
**Solución:** Presupuesto mínimo 60%, ideal 75%

## 📈 Casos de Éxito

### Caso 1: Reducción de Gastos en Delivery

**Antes:**
```
Mes 1: Comida = $3,000 (20%)
  - Restaurantes/Delivery: $2,000
  - Supermercado: $1,000
```

**Estrategia:**
1. Identificó patrón con filtros
2. Estableció límite: Max 2 deliveries/semana
3. Planificó comidas semanalmente

**Después:**
```

  - Restaurantes/Delivery: $500
  - Supermercado: $1,300
Ahorro mensual: $1,200
```

### Caso 2: Control de Tarjetas

**Antes:**
```
Visa: $8,000 (60% del gasto)
MasterCard: $500
Efectivo: $1,500
```

**Problema:** Excediendo límite de Visa

**Solución:**
1. Distribuyó gastos
2. Visa: Supermercado (descuento 15%)
3. MasterCard: Servicios (sin interés)
4. Efectivo: Gastos diarios pequeños

**Después:**
```
Visa: $4,000 (30%)
MasterCard: $3,500 (26%)
Efectivo: $2,500 (19%)
Mejor control + Más beneficios
```

## 🔐 Seguridad de Datos

### Backup Manual (Recomendado Mensual)

1. **Exportar CSV:**
   - Ajustes → Exportar Datos a CSV
   - Guarda en carpeta segura

2. **Ubicaciones sugeridas:**
   - Google Drive (carpeta privada)
   - Correo a ti mismo
   - Almacenamiento local del teléfono

3. **Nomenclatura:**
   ```
   gastos_2024_enero.csv
   gastos_2024_febrero.csv
   ```

### Antes de Resetear/Cambiar Teléfono

1. Exporta todos los datos
2. Verifica que el CSV tiene todo
3. Guarda en múltiples lugares
4. Solo entonces borra o cambia de dispositivo
